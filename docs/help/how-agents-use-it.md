Published context only, one answer line first, and what happens when nothing is written down.

## What an agent reads

- Only what an owner published. A suggestion changes nothing until it is published.
- Every answer starts with an answer line, in the app and in your own agent.
- Not found is said plainly, never filled in.

## Following links

An agent can follow a link between context items, definitions and domains, one step at a time, to read what it points to. An archived item is never followed, and following never changes what an answer includes. Admins can switch it off in Agents and access.

## Agents offer, people decide

When something is missing or wrong, an agent offers to tell the owner, and sends only after the person says yes.
